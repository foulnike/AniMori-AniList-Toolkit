# Документация приложения

Здесь только про десктопное приложение AniMori 3.0.

Юзерскрипт живёт в ветке `script` и документируется там же. Ветка `main`
заморожена и хранит гибрид 2.x таким, каким он был на последнем
выпуске. Правило целиком: документация ветки описывает только её продукт,
а про соседний — ровно столько, сколько нужно для решений в этом
(`CONVENTIONS.md`, раздел «Документация»).

## С чего начинать

Два первых файла читаются до первой правки, остальные — по надобности.

| Файл | Отвечает на вопрос |
| --- | --- |
| `REPO-LAYOUT.md` | Какие есть ветки, что в каждой лежит, как переносить правки ядра |
| `CONVENTIONS.md` | По каким правилам живут код и документация: слои, инварианты, коммиты |
| `ARCHITECTURE.md` | Как устроено приложение целиком: ядро, слой данных, мост |
| `ARCHITECTURE-SHELL.md` | Что делает оболочка на Rust: окна, команды, права, обновление |
| `ARCHITECTURE-UI.md` | Как собран интерфейс: экраны, роутер, компоненты, тема |
| `ARCHITECTURE-VIDEO.md` | Почему в приложении нет просмотра и каким он будет |
| `STORAGE-AND-SYNC.md` | Где лежат данные, как работает локальный снимок и синхронизация |
| `DATA-PIPELINE.md` | Откуда берутся данные о тайтлах и людях и что с ними делают |
| `DECISIONS.md` | Почему сделано так, а не иначе, и что было отвергнуто |
| `ROADMAP.md` | Что делается дальше и в каком порядке |

Описание самого продукта — что умеет, чего не умеет, как собрать и выпустить —
в `README.md` в корне ветки.

## Чего здесь не ищите

Перевод по словарю, шапка юзерскрипта, выкладка на Greasy Fork, блокировщик
рекламы, встраивание в чужую разметку и манга — не часть этого продукта.
Где это теперь искать — в `REPO-LAYOUT.md` и в таблице «Чего здесь нет»
корневого `README.md`.

Снятые с эксплуатации документы гибрида 2.x, наброски про приставку и
снимки прежнего продукта здесь больше не хранятся — они целиком есть
в замороженном `main` и в уже вышедших релизах.

## Что осталось не вычищено

Документы приведены к одному продукту: юзерскрипт, словарь,
блокировщик и надстройка над чужой страницей упоминаются только там,
где это нужно для решений здешнего продукта.

Незакрытым остался код, а не тексты. В ядре ещё живут адрес словаря
`DICT_URL` и правила перевода глав и томов — обоим обращаться некуда:
клиента словаря и переводчика в ветке нет. Где что чистить — в `ROADMAP.md`.

Часть документов крупнее 25 КБ и правится локально, а не через API —
почему именно так, сказано в `CONVENTIONS.md`, раздел «Размер файла».
