# Соглашения

Правила, по которым живёт код и документация. За большинством пунктов
стоит дефект, который уже случился.

---

## Слои и зависимости

```
userscript/  и  app/        знают разметку
        ↓
shared/features → api/ → bridge/
        ↓          ↓
      core/  ←─────┘
        ↓
      utils/
```

- `shared/` не знает о `userscript/` и `app/`. Иначе цикл импортов и падение
  на старте, а второй продукт тащит за собой чужие виджеты.
- Между слоями импорт только алиасом, относительные пути — внутри своего
  каталога.
- К `GM_*` и `@tauri-apps/*` никто не обращается напрямую, только через мост.
  Мост импортируется как `@/bridge`, блокировщик — как `@adblock-impl`.
- Сетевые вызовы живут только в `shared/api/`. Виджет, стучащий в сеть сам,
  обходит ограничитель темпа и рано или поздно ловит 429.
- `shared/utils/` не импортирует ничего, кроме типов.
- Свой экран не ходит в сеть и в хранилище сам, только через слой данных.

Известное нарушение: `shared/utils/vue-mounter.ts` берёт `NO_TRANSLATE_CLASS`
у переводчика.

## Инварианты

Нарушение каждого уже приводило к дефекту.

1. Платформенный модуль выходит проверкой платформы на первой строке.
2. Каждый сетевой запрос берёт слот у ограничителя темпа и задаёт
   `credentials`. Для `graphql.anilist.co` всегда `omit`: с куками сервис
   отвечает 403 через Cloudflare.
3. Молчаливый `catch` запрещён. Либо обработка, либо запись в журнал.
4. Селекторы берутся из живого DOM, а не из предположений о разметке.
5. Чужие узлы прячутся, а не удаляются: удаление ломает разметку React.
6. Тумблер видимости не отменяет монтирование компонента.
7. Вложенные реактивные ссылки объявляются поверхностными.
8. Задачи смены роута идемпотентны.
9. Шапка юзерскрипта не расширяется без крайней нужды: каждое право
   проверяется модерацией Greasy Fork.
10. Настройка, способная убить страницу, не управляется только из этой
    страницы. Нужен внешний выход из оболочки.
11. Список меняется только через `queueEdit()`.
12. Взрослое отбирается только через `adult.ts` и только на слое показа.
    Из баз и с сервера оно не вырезается никогда.
13. Цвета и радиусы — только токенами темы.
14. Новый внешний адрес прописывается в двух местах сразу: `connect`
    в шапке юзерскрипта и разрешения http в `capabilities/default.json`.
    Без второго он работает только в одной из сборок.

## Размер файла

Потолок — 25 КБ, и он касается только исходников. Причина техническая,
а не эстетическая: правки через API рвутся на файлах крупнее, и текст
молча теряет середину. Это уже случалось с `proxy.rs` (`e5e109a`).

Файлы, которые сейчас за потолком и подлежат разрезанию до следующей
крупной правки:

| Файл                              | Размер |
| --------------------------------- | -----: |
| `src/app/screens/MediaScreen.vue` | 45 762 |
| `src/userscript/style.scss`       | 45 286 |
| `src-tauri/src/auth.rs`           | 26 482 |
| `src/app/screens/ListsScreen.vue` | 25 646 |

Первый из них — тот самый файл, который придётся править при переходе
на датасет названий. Резать его надо до того, как туда лезть.

### На документацию потолок не распространяется

Резать справочник по размеру — ровно та ошибка, из которой выросла
карта проекта из семи частей и шесть файлов решений. Разложенный
по кускам справочник читается хуже цельного, а узнать, что тема
продолжается в соседнем файле, можно было только дочитав первый
до конца.

Сейчас под исключение попадает только `ARCHITECTURE.md`.

Риск разрыва при записи от этого не исчезает, поэтому взамен два
требования: большой документ перезаписывается целиком одной
операцией, а не серией частичных правок, и после записи его надо
перечитать. Разрыв не даёт ошибки — запись отвечает успехом и теряет
середину молча.

## Комментарии

Комментарий объясняет причину, а не действие. «Увеличиваем счётчик»
не нужно никому; «счётчик общий на зеркала: лимит считается по IP»
нужно всем.

Раньше здесь стояли жёсткие потолки: три строки на шапку файла, две
на доккомментарий, одна на строчный. Они сняты. Потолки появились как
защита от рвущихся при записи файлов — лечили инструмент через стиль.
Резать надо файлы, а не мысли.

Что по-прежнему запрещено:

- Хронология в комментарии: «правка после…», «статус на дату», «пункт 4.5».
  История живёт в git, комментарий описывает настоящее.
- Комментарий, повторяющий имя функции.
- Закомментированный код. Он есть в истории.

Длина строки — 100 знаков. Форматирование — `npm run format`.

## Работа с репозиторием

Рабочая ветка — `app-3.0-dev`. Перед коммитом прогоняется `npm run format`.
Тайпчек звать отдельно не нужно: `build`, `build:app` и `build:tauri`
сами начинают с `typecheck:all`. Неиспользованный импорт роняет тайпчек,
а значит и сборку.

Тело коммита — три-восемь строк о том, что было не так и что отвергнуто.
Заголовок описывает результат, тело — причину.

Алиасы слоёв живут в трёх местах и правятся только вместе: `resolve.alias`
в `vite.config.ts`, `paths` в `tsconfig.json` и в `tsconfig.shared.json`.
Расхождение даёт зелёную сборку при красном тайпчеке или наоборот.

Новая команда оболочки заводится в трёх местах: `#[tauri::command]`
и `invoke_handler` в `lib.rs`, `AppManifest::commands` в `build.rs`,
разрешение в нужном файле `capabilities/`. Пропуск третьего даёт отказ
в рантайме без ошибки компиляции. Для вызова из разметки добавляются
ещё тип в `IBridge`, реализация в `TauriBridge` и заглушка в `MonkeyBridge`
— без последней браузерная сборка падает на тайпчеке.

## Документация

Документ описывает состояние, а не хронику. Устаревшее удаляется,
а не зачёркивается: история уже есть в git.

Из этого следует:

- **Нет файлов с номерами.** Если документ разросся, значит в нём лежит
  то, что уже неправда. Надо чистить, а не заводить следующий по счёту.
- **Нет дат в заголовках разделов.** Дата нужна ровно один раз —
  в строке отмены, чтобы понять, что чему предшествовало.
- **Нет пометок «отменено».** Отменённое стирается, а причина отмены
  переезжает в актуальную запись.
- **Причина ценнее формулировки.** Через полгода возвращаются за «почему»,
  а не за «что». Пишите развёрнуто: короткая запись, смысл которой забыт,
  бесполезна ровно так же, как её отсутствие.
- **Размер не повод делить.** Повод делить — только другая предметная
  область.

Семь файлов в `docs/`, и восьмого не появляется без новой предметной
области. Новый месяц предметной областью не считается.
