# Соглашения: только про юзерскрипт

Ветка `script` собирает один продукт — файл `animori.user.js`, который расширение пользователя вставляет в страницу AniList. Отсюда все правила ниже: мы гости в чужом приложении и не владеем ни DOM, ни маршрутизацией, ни жизненным циклом страницы.

Про настольное приложение здесь нет ничего и быть не должно — ему отведена ветка `app-3.0-dev` со своими соглашениями.

## Слои

```
main.ts  →  features/  →  api/  →  core/  →  utils/
                 ↓
             bridge/
```

Зависимости текут только вправо.

| Слой | За что отвечает | Чего ему нельзя |
| --- | --- | --- |
| `main.ts` | Порядок запуска и больше ничего | Логика возможностей, работа с сетью |
| `features/` | Возможности: интерфейс, переводчик, поиск, медиа, сканер, перенос списка | Обращаться к `fetch`/`GM_*` напрямую, знать друг о друге |
| `api/` | Вся сеть: AniList, Шикимори, anime365, AnimeThemes, словарь | Знать про DOM и про Vue |
| `core/` | Настройки, БД, словарь, жизненный цикл, здоровье сети, акцент, константы | Знать про конкретные возможности |
| `bridge/` | Единственная дверь к `GM_*` | Всё остальное |
| `utils/` | DOM, журнал, сверка названий, монтирование Vue | Импортировать что-либо выше себя |

Две возможности друг друга не импортируют. Нужно общее — оно переезжает в `core/` или `utils/`.

## Два алиаса

| Алиас | Ведёт на | Зачем |
| --- | --- | --- |
| `@bridge-impl` | `src/bridge/MonkeyBridge.ts` | Доступ к `GM_*` одним объектом |
| `@adblock-impl` | `src/features/adblock/impl.noop.ts` | Заглушка: блокировщика в браузере у нас нет |

Алиасы — наследство общей сборки с десктопом, но их оставили нарочно: они держат вызовы `GM_*` и заглушку блокировщика в одном месте. Импорт вида `import { ... } from '@adblock-impl'` — правильный, прямой импорт `impl.noop.ts` — нет.

## Инварианты

То, что ломается тише всего и больнее всего.

1. **Каждый шаг запуска — через `step()`.** Ошибка одного шага попадает в журнал и не срывает остальные. Новая возможность без `step()` способна погасить весь скрипт.
2. **Старт только после `document.body`.** Ждём в `whenDomReady()` опросом каждые 16 мс. Расширение вставляет нас раньше, чем браузер собрал страницу.
3. **Чужая страница — выход.** Если это не AniList, `bootstrap()` обрывается до любого вмешательства в DOM.
4. **Запросы к AniList — только через `api/rate-limit.ts`.** Очередь держит потолок запросов; прямой `fetch` по адресу `graphql.anilist.co` приводит к 429 и молчаливой потере данных.
5. **Никаких молчаливых `catch`.** Любой поглощённый сбой — строка в `Logger`. Пустой `catch {}` в коде — ошибка ревью.
6. **Постраничные Vue-приложения снимаются при смене маршрута.** Регистрируйте уборку через `registerRouteTask`; то, что живёт всю сессию — через `registerShutdownTask`. AniList — SPA, без этого корни накапливаются.
7. **Фантомные корни подчищаются.** Узлы `am-vue-root`, потерявшие владельца, сносит задача `vue:phantoms`.
8. **Своё не переводим.** Собственные узлы помечаются классом `am-notr` (`NO_TRANSLATE_CLASS`), иначе переводчик перепишет наш же интерфейс.
9. **`GM_*` — только через `MonkeyBridge`.** Ни одна возможность не вызывает `GM_xmlhttpRequest`, `GM_setValue` и прочее напрямую. Разрешённые гранты перечислены в шапке в `vite.config.ts`; новый грант означает повторный вопрос разрешений у всех пользователей.
10. **Тяжёлая уборка — отложенно.** Сборщик мусора запускается через 15 с после старта, чтобы не отнимать время у первой отрисовки.
11. **Версия и платформа — только из подстановок.** `__ANIMORI_VERSION__` и `__ANIMORI_PLATFORM__` подставляет сборка; число версии руками в коде не пишем.
12. **Схема БД меняется только вперёд.** `AniMoriSuperDB`, версия 6. Новое хранилище — поднять номер и дописать миграцию; старые миграции не правим — у пользователей база уже создана.

## Размер файла

Потолок — 25 КБ на исходник. Сегодня его пробивают три файла:

| Файл | Байт | Состояние |
| --- | --- | --- |
| `src/style.scss` | 45 286 | За потолком вдвое; разбить по возможностям |
| `src/features/translator/index.ts` | 39 053 | За потолком вдвое; просится раздел на обход DOM и правила |
| `src/features/scanner/compare.ts` | 25 192 | Чуть сверх; терпимо |
| `src/features/ui/SettingsModal.vue` | 23 327 | На грани |
| `src/features/exporter/sync-api.ts` | 21 110 | В норме |

Правило не в том, чтобы срочно резать эти файлы, а в том, чтобы не добавлять в них новое. Пришли править `translator/index.ts` — сначала вынесите часть рядом, потом дописывайте.

Измерять, а не вспоминать:

```bash
git ls-files -s src | awk '{print $4}' | xargs wc -c | sort -rn | head -20
```

## Проверки перед коммитом

```bash
npm run format      # prettier по src/**/*.{ts,vue,scss} и корневым *.{ts,json,md}
npm run typecheck   # vue-tsc --noEmit
npm run build       # проверка типов + сборка dist/animori.user.js
```

`npm run build` обязателен: проверка типов не ловит ошибки шапки юзерскрипта и путей алиасов. Проверка типов сразу после `git switch` падает с `TS2688: Cannot find type definition file for 'greasemonkey'` — это не ошибка кода, а чужие `node_modules` от ветки приложения; см. `REPO-LAYOUT.md`.

Сборка намеренно без минификации: Greasy Fork требует читаемый источник, да и разбирать чужие отчёты об ошибках по сжатому файлу невозможно.

## Работа с репозиторием

- Один коммит — одно решение. Заголовок по-русски, без точки в конце.
- Тело — 3–8 строк: зачем это сделано и какие варианты отвергнуты. Что именно поменялось, видно из диффа.
- Историю не переписываем: ни `rebase` опубликованного, ни `push --force`.
- Тело коммита набираем в Git Bash или редакторе. PowerShell 5.1 портит кириллицу в `-m` и не знает `&&`.
- Правка словаря и правка кода — разные коммиты.

## Документация

В `docs/` три файла, и расти они не должны без повода: `REPO-LAYOUT.md` — границы веток, `CONVENTIONS.md` — этот файл, `ARCHITECTURE.md` — устройство скрипта.

Главное правило: **документация ветки описывает только её продукт.** Если абзац объясняет устройство оболочки, окна или Rust — его место в другой ветке. Упоминать другой продукт можно одной строкой в смысле «этого здесь нет».

Устаревшие абзацы удаляем, а не помечаем «устарело»: история есть в `git log`, а читатель верит первому абзацу, до которого дошёл.
