# План 3.0

Собственный клиент AniList вместо надстройки над сайтом. Скрипт остаётся
на общем ядре и поддерживается исправлениями.

## 3. Оболочка и экраны

- [x] 3.1 Точка входа приложения и окно на своём ресурсе · 0d58a47
      Окно `main` грузит свою сборку, `frontendDist` указывает на `dist/app`,
      а команды перед сборкой готовят оба выхода: без бандла скрипта
      в `dist` падает `include_str!` в `hybrid.rs`
      Гибридное окно с настоящим сайтом переехало в `hybrid.rs` под меткой
      `site` и открывается вторым окном командой `animori_open_site`
      Права окон разделены: `capabilities/default.json` и `capabilities/site.json`
- [x] 3.2 Каркас экранов и переходы между ними · f4e4d53
      Свой маршрутизатор в `src/app/router` на хэше адреса, без vue-router
      Адреса вида `#/lists` и `#/media/21`; неизвестный адрес ведёт на главную
      Рамка окна — `components/AppShell.vue`: меню, шапка, «Назад»
      Новый экран = три места: `SCREEN_NAMES`, `SCREEN_TITLES`, `SCREENS` в `App.vue`
      Палитра в переменных `--am-*`; экраны пока заглушки
