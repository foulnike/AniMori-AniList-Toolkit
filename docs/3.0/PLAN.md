# План 3.0

Собственный клиент AniList вместо надстройки над сайтом. Скрипт остаётся
на общем ядре и поддерживается исправлениями.

Подробности пункта — в его коммитах, причины решений — в `DECISIONS.md`
и его второй и третьей частях. Этапы с пятого по восьмой — в `PLAN-2.md`.
