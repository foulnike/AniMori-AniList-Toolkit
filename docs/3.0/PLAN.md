# План 3.0

Своё приложение вместо надстройки над сайтом: свой список и своя
статистика на оси номеров MAL, глубина из AniList, язык из русских баз.
Скрипт остаётся на общем ядре и поддерживается исправлениями.

Подробности пункта — в его коммитах, причины решений — в `DECISIONS.md`
и его частях со второй по пятую. Здесь три сделанных этапа;
плеер и всё позднее — в `PLAN-2.md`.
