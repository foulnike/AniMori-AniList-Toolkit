# Контекст 3.0

Курс: свой клиент вместо надстройки. Первая цель — Windows. Список,
избранное и статистика — свои, обмен с чужими сервисами файлом.

## Где стоим

Этапы 1 и 2 закрыты: в слое данных есть тип записи, тома, метка
взрослого, латиница в самом снимке, пересмотры, даты начала
и конца и личный комментарий. Версия снимка — 5.

Из третьего закрыто всё до 3.5 включительно: окно, каркас, единая тема,
списки и полки сеткой постеров, добор списка за сотней, карточка
с баннером и панелью «Моя запись», окно правки со всеми полями,
поиск на два языка и живая главная. Манга — подвкладка списков,
отдельного экрана манги в дереве больше нет.

Следующий шаг — 3.6: настройки, словарь и свои ссылки; панели
того экрана уже собраны, но содержания за ними почти нет.
План — в `PLAN.md` и `PLAN-2.md`, реестр решений — в пяти частях.

## Помеха снята

AniList держал временные ограничения API с 15 по 17 августа: анонимный
запрос отвечал 403. Клиент пережил без правок, сейчас API отвечает.

## Запасная база видео

AniLiberty разведана руками: `anilibria.top/api/v1` отвечает без ключа,
потоки hls отдаются прямо. Кода пока нет, пункт 4.6.

## Чего не знаем

- Вес ответа `MediaListCollection` на большом списке не мерян,
  постраничного обхода в коде нет; теперь запросов два, на два типа.
- Ответ сервера на негодную правку не видели.
- Сколько тайтлов остаётся без русского названия, не считали.
- Время записи снимка вместе с дублем в файл не меряли.
- Подъём из файла при пустом хранилище вживую не проверялся.
- Отдаёт ли AniList выгрузку списка в MAL-совместимом XML.
- Равен ли номер Шикимори номеру MAL всегда: поиск на этом стоит.

## Долг кода

- `files.rs`: временный файл остаётся, если переименование не удалось.
- Дубль снимка пишется на каждое сохранение, а не по двум точкам.
- Кнопка «К манге» на главной зовёт списки без вида: откроется аниме.
- `isRussianWord` в `media-search.ts` экспортируется, но никем не зван.
- Облик тайтла лежит в сторе `shikiCache` под `LOOK1_`, хотя к Шикимори
  отношения не имеет.
- Экран настроек текстом обещает то, что будет в 3.6 и 3.7.
