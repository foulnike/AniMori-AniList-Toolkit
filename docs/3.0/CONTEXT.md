# Контекст 3.0

Курс: свой клиент вместо надстройки над сайтом. Первая цель — Windows.

## Где стоим

Этап 2 закрыт целиком: мост, вход, запросы из оболочки, слой данных.
Слой данных собран, но звать его некому: `initCollection()`,
`startEditSender()` и `refreshFromServer()` не вызываются ниоткуда.
Устройство слоя — в `docs/PROJECT-MAP-DATA.md`.

Следующий шаг — 3.3, экран списков. Он же первая живая проверка данных.

## Помеха

AniList закрыл API: любой запрос к `graphql.anilist.co` отвечает 403,
сайт при этом жив. Клиент это переживает: 403 считается отказом сервера,
пауза растёт до пятнадцати минут, очередь правок не тратит попытки.
Живая проверка списка до возврата API невозможна.

## Чего не знаем

- Живого запроса из своего окна не было ни одного.
- Вес ответа `MediaListCollection` на большом списке не мерян,
  а постраничного обхода в коде нет.
- Ответ сервера на негодную правку не видели: ветка отказа
  по содержанию не проверялась.
- Сколько тайтлов остаётся без русского названия, не считали.
- Время записи снимка вместе с дублем в файл не меряли.

## Долг кода

- `files.rs`: временный файл остаётся в каталоге, если переименование
  не удалось.
- Дубль снимка пишется на каждое сохранение, а не только на уходе
  в фон и закрытии.
