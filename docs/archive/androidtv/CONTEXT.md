# Контекст порта на Android TV

## Где остановились

Разведка закончена, кроме пункта 1.6. Оболочка работает целиком: Rust
собирается, apk ставится, движок грузится, бандл исполняется.

Чёрный экран оказался бедой не порта: `anilist.co` с телевизора висел, а
`example.com` и `s4.anilist.co` отвечали за 531 и 165 мс; `ping` уводил на
`8.47.69.1`. VPN на телевизоре открыл сайт сразу — диагноз закрыт.

Сразу после этого наш интерфейс появился и стёрся сам через несколько
секунд. Причина — двойной прогон бандла: второй экземпляр с пустым
реестром сносил корни первого, а уборка фантомов первого — корни
второго. Шесть предупреждений про «брошенные корни» в журнале — ровно по
числу наших приложений. Точка входа теперь держит отметку прогона и
второй останавливает (`230f223`). Живой проверки правки ещё не было.

## Состояние ветвей

- `androidtv-dev` — активная, рабочая папка `D:\Renforge\Animori TV`
- `script&windows-dev` — версия 2.0.1 и скрипт, порт её не трогает
- `main` — релизная, тег `v2.0.2`, папки `docs` в ней нет намеренно
- Патч 2.0.3 заморожен в запасе и не выпускается
- В `main` из порта ничего не уходит до конца работы

## Что ждёт порт

Следующее по очереди — живая проверка отметки прогона и затем пульт
(раздел 4): интерфейс сделан под мышь, а у пульта есть только фокус.
Прокси (2.2) остаётся обязательным для выпуска, но разработку больше не
держит: на телевизоре стоит VPN.

## Уроки

- Сеть проверять до правки кода: пустой экран бывает чужой бедой
- Перед выводом спрашивать, что именно видел человек: «пропал от пульта»
  и «пропал сам» — разные причины
- Запись в API выше ~34,7 КБ молча бьётся — перечитывать файл целиком
- Кириллицу писать напрямую, без `\u`-экранирования
- Журнал снимается только через `force-stop`, паузу 40 с и фильтр `--pid`
- Цель в `chrome://inspect` видна только пока приложение живо
- Сборка без установщика — `tauri build --no-bundle`
