Номера версии у порта пока нет: он не патч, а отдельное направление.

## 2. Платформенная развилка оболочки

Три подсистемы написаны под Windows и на Android не существуют в этом виде.
Задача не «починить», а развести реализации по платформам.

Под `cfg(windows)` эти места в сборку не попадают, то есть компилятор
на них молчит. По вылету по пункту 1.5 они оказались ни при чём:
в apk их нет вовсе, виноват был поставщик TLS у самого Tauri.

Разведена только Rust-часть. Клиентские части тех же подсистем в apk
попадают и работают: тумблер адблока стучится в зону `.invalid`,
перехватчика там нет, и запрос тихо умирает — так и задумано.

- [ ] 2.1 Адблок: сейчас цепляется к движку WebView2 через `webview2-com`
- [ ] 2.2 Прокси: сейчас он передаётся аргументами командной строки
      движку; без него сайт на телевизоре не открывается. На время
      разработки обходим VPN на телевизоре, так что пункт больше
      ничего не блокирует, но без него порт нельзя отдавать людям
- [x] 2.3 Окно: память размера, полный экран, центрирование — разведены
      через `cfg(desktop)` — `6f63b74`
- [ ] 2.4 Обновлятор: релизный канал и `latest.json` рассчитаны на установщик;
      на телевизоре проверка уже отвечает «Unsupported OS» в журнал
- [x] 2.5 Двойной прогон бандла: второй экземпляр с пустым реестром сносил
      корни первого, а уборка фантомов первого — корни второго, и наш
      интерфейс стирался сам через несколько секунд после загрузки;
      точка входа теперь держит отметку прогона — `230f223`
- [ ] 2.6 Остаток от двойного прогона: скрипты самого Tauri сыплют
      «Cannot redefine property» в консоль; работе не мешает, но шумит
