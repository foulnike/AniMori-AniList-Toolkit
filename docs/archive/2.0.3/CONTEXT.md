## Устройство вкладки «Поддержать»

`src/features/ui/SettingsSupportTab.vue` — две карточки: «Поддержать
проект» с кнопками звезды, обратной связи и блога, и «Поделиться» с
полем адреса. Адреса лежат константами в `settings-state.ts`:
`SUP_GITHUB`, `SUP_GREASY`, `SUP_GREASY_FEEDBACK`, `ISSUES_CHOOSE`,
`SUP_DTF`. Кнопка обратной связи и адрес для отправки другу разные у
скрипта и приложения, развилка через `Bridge.platform === 'tauri'`;
кнопка блога одна на обе версии. Открытие — через `window.open`, в
приложении его перехватывает оболочка и отдаёт браузеру.
Идентификаторы `am-sup-*` сохраняются: на них смотрят живые копии.

## Уроки, действующие с прошлых версий

- Запись файла через API обрезается около 34,7 КБ: после большой записи
  проверять хвост файла
- Кириллицу в аргументы инструмента писать напрямую, без `\u`-escape:
  иначе вместо «ё» в файл попадает посторонний знак, а типы и сборка
  такое не ловят
- Добавил имя в готовый импорт — посчитай длину строки: лимит 100
- В имени ветки есть `&`, в PowerShell её имя всегда в кавычках
- Полная сборка `tauri build` без ключа подписи падает: локально
  собирать с `--no-bundle`, подписанный установщик делает Actions
